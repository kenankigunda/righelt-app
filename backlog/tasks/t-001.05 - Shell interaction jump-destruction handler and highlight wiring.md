## Description

Wire the sub-bullet click interaction in `app.js`:

- Add `jump-destruction` action handler: read `data-move-index`, `data-position-row`, `data-position-col`; call `transport.selectHistoryMove({gameId, moveIndex})`; then call `boardRuntime.setDestructionHighlight({row, col})`.
- Reuse existing `startHistoryPress` / `playHistoryReleaseBounce` / `clearHistoryPress` pattern for pressed state feedback (one continuous motion per AC14).
- Add `jump-destruction` to the no-busy-state-start exclusion list (matching the existing pattern for `jump-history`).
- Clear destruction highlight on `return-live` action handler.
- Clear destruction highlight at the start of `jump-history` handler (before snapshot load) so prior highlight does not persist when navigating without a sub-bullet.
- Gate hover styles on sub-bullets with `data-hover-capability="hover"` (AC15).
- Ensure tap target for sub-bullets meets minimum touch comfort size (AC15, §7.5).
