## Scope

Write Playwright E2E tests covering the representative success and recovery workflows from the test plan. Tests should use the existing local Pages + API stack harness.

Minimum required test coverage (each must pass in CI):

- **Player leave from home-page card** (E-05): card animates out without confirmation.
- **Player leave from game page + banner + rejoin** (E-06, E-07): "You have left the game" overlay blocks UI; "Rejoin as player" restores seat without approval prompt.
- **Last-player delete** (E-10): game disappears from home-page list; appears in trash bin.
- **Viewer "Game deleted" overlay in real time** (E-11): using two concurrent browser contexts — viewer sees overlay without refreshing when the last player deletes.
- **Restore from trash bin card** (E-16): game moves from trash back to home-page list.
- **"Game not found" screen** (E-17): navigating directly to a non-existent game ID shows the minimal "Game not found" screen.
- **Viewer leave** (E-18): viewer arrives at join-decision screen; no notification to remaining player.
- **Offline disabled state** (E-19): simulate offline by disabling network in Playwright; leave/delete option shows explainer, not silently hidden.
- **Playground mode "Delete"** (E-20): single device, both seats; hamburger shows "Delete".

Additional multi-client tests (mark as recovery/multi-client in test file):
- **Player 2 sees seat vacated in real time** (E-21): two concurrent browser contexts.
- **Reconnect role restore after rejoin** (E-24): leave, rejoin, reload — role correctly restored.
