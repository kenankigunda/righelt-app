## Scope

- Add `applyLeavePlayer(game, identityId)` mutation helper to `shell-live-core.ts`:
  - Frees the player's seat.
  - If another player remains: adds notification "Player left", returns `{ deleted: false }`.
  - If no other player remains (or `selfPlayMode`): calls `applySoftDelete`, adds notification "Game deleted", returns `{ deleted: true }`.
- Add `POST /leave` handler to `GameRoomDO`:
  - Validates caller is a player; rejects non-players with `role_not_allowed`.
  - Rejects already-deleted games with `game_already_deleted`.
  - Calls `applyLeavePlayer`, commits, broadcasts `player_left` or `game_deleted` event.
- Add `POST /restore` handler to `GameRoomDO`:
  - Validates caller is a player; rejects viewers with `role_not_allowed`.
  - Rejects non-deleted games with `game_not_deleted`.
  - Calls `applyRestore`, commits, broadcasts `game_restored` event.
- Add `POST /leave-viewer` handler to `GameRoomDO`:
  - Removes caller from viewers list; no notification or broadcast.
- Add `getTrashSectionWhereClause` to `shell-live-db.ts`:
  - `trash-my`: `deleted_at IS NOT NULL AND (player1_identity_id = ? OR player2_identity_id = ?)`.
  - `trash-other`: `deleted_at IS NOT NULL AND player1_identity_id != ? AND player2_identity_id != ?` (identity was a viewer).
- Update `getHomeSectionWhereClause` to add `AND deleted_at IS NULL` for `my` and `other` sections.
- Wire `trash-my` and `trash-other` section keys in `shell-live.ts` HTTP handler.
