## Scope

- Add `renderCardMenu(game, { isOffline, myIdentityId })` helper in `app.js`:
  - Renders a `⋮` button at top-right of the card with accessible pressed/hover states gated by `data-hover-capability`.
  - Menu item: Leave or Delete (computed by `computeLeaveDeleteLabel`), styled as destructive.
  - When offline: item visibly disabled with inline explainer "Not available offline".
  - Always reserves layout space for the menu button regardless of game state (no layout shift on sibling cards — per UI_INFORMATION_ARCHITECTURE_PRINCIPLES.md Game Card Rule).
  - Tap target meets minimum mobile size.
- Inject `renderCardMenu` into `renderHomeGameCard`.
- Wire `data-action="leave-game"` and `data-action="delete-game"` click handlers in `app.js` event dispatcher:
  - Call `transport.leaveGame(gameId)`.
  - On success: animate card out of the home-page list using smooth collapse (120–220ms, respects `prefers-reduced-motion`).
  - On offline guard: show inline feedback (no action).
- Add "You have left the game" overlay:
  - Triggered when `leftGameBannerByGameId.get(gameId) === true` while on game route.
  - Reuses `invite-gate` CSS pattern: full-width top-of-page, background `aria-hidden="true"`.
  - Animates in (120–220ms easing, respects `prefers-reduced-motion`).
  - Contains "You have left the game" heading and "Rejoin as player" button.
  - "Rejoin as player" calls `transport.joinGame({ gameId, mode: "player", inviteFromRole: myCurrentRole })` (immediate — no approval needed since re-joining own former seat).
  - On successful rejoin, clear `leftGameBannerByGameId` entry and re-render game normally.
