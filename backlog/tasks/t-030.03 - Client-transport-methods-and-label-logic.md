## Scope

- Implement `computeLeaveDeleteLabel(game, identityId)` pure function:
  - Returns `"Delete"` when identity is the only player or `selfPlayMode === true`.
  - Returns `"Leave"` when another player occupies at least one seat, or caller is a Viewer.
- Add `leaveGame(gameId)` to `createLiveTransportStore`:
  - Calls `POST /leave`, updates local game cache, emits change event.
  - Returns `{ ok, deleted, game }`.
- Add `restoreGame(gameId)` to `createLiveTransportStore`:
  - Calls `POST /restore`, updates local game cache.
- Add `leaveAsViewer(gameId)` to `createLiveTransportStore`:
  - Calls `POST /leave-viewer`, removes game from local cache or updates role.
- Add `leftGameBannerByGameId: Map<string, boolean>` module state to track "You have left" overlay per game (local-only, not persisted).
- Handle incoming `player_left` WebSocket event: update authoritative game, emit change.
- Handle incoming `game_deleted` WebSocket event: mark game as deleted in local cache, emit change so game-page overlay can appear.
- Handle incoming `game_restored` WebSocket event: clear deleted flag, emit change.
- Add offline guard: `leaveGame` and `restoreGame` reject with `{ ok: false, error: "offline" }` when transport detects no connectivity.
- Propagate `deletedAt` field through `upsertGameSnapshot` and `homeGameCardById`.
