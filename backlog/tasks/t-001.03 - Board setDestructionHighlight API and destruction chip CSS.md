## Description

Add destruction highlight capability to the board runtime public API:

- Introduce `destructionHighlight` internal state variable (type `{row: number, col: number} | null`) in `board-runtime.js`.
- Add two public methods to the returned interface:
  - `setDestructionHighlight(position: {row, col})` — sets the highlight coordinate.
  - `clearDestructionHighlight()` — clears it to null.
- Auto-clear on any `loadSnapshot` call.
- Render the destruction-square chip overlay when position is set; use a dedicated CSS class distinct from continuation/selection/retreat chip roles (per `RIGHELT_WEB_APP_SPEC §1.1.4`).
- The highlight must NOT affect the board's actual state or snapshot (visual-only overlay).
