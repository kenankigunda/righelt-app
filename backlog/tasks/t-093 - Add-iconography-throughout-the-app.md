## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Notion priority: P1.

Add iconography throughout the app to improve clarity, scanability, visual character, and overall polish across key UI surfaces. This should be treated as part of the app's broader visual-language work rather than as a set of isolated icon additions.

The goal is to identify where iconography would meaningfully improve the interface, define an intentional icon usage style, and apply it coherently across the app where it strengthens comprehension or brand feel.

Potential scope:
- Audit the app for places where iconography would improve understanding, affordance clarity, hierarchy, or visual rhythm.
- Define a coherent iconography approach so icons feel like part of a system rather than a patchwork of unrelated additions.
- Add icons to appropriate surfaces such as navigation, actions, metadata, status treatments, prompts, and other repeated UI patterns where they improve the experience.
- Avoid decorative icon usage that adds noise without improving usability or brand coherence.
- Cross-link with `T-087` (Holistically refine UI feel, brand, and forward UI principles), since the broader UI-feel/brand work may guide or absorb this effort.
- Add or update regression/guard coverage where concrete icon-related UI contracts become important to preserve.
