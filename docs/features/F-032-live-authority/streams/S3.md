# Stream S3 - Frontend Rewrite To Live Game Session Client

## Scope
- Rewrite the shell client to use the new game-scoped websocket protocol for both invite and game routes.
- Remove the old invalidation websocket model and fixed invite or game passive refresh loop.
- Make pushed `game` payloads authoritative for invite and game rendering.

## Non-Goals
- No backend GameRoomDO implementation ownership.
- No home-page polling redesign.
- No offline playground rewrite.

## Deliverables
- Rewritten `apps/web/shell/live-sync.js` with `heartbeat`, `ack`, reconnect, and `lastEventSeq` support.
- Updated `apps/web/shell/live-transport.js` to cache websocket-pushed game state and recovery fetches.
- Updated `apps/web/shell/app.js` so invite and game routes both open live sessions and stop relying on `/presence`.
- Removal of old code that points at `/api/shell/ws?scope=...`.
