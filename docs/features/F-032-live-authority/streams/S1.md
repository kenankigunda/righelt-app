# Stream S1 - Foundation Contracts, Schema, And Harness

## Scope
- Define the new DO-backed live authority contracts with no legacy transport carryover.
- Add the persistence schema and shared repository or harness foundations required by downstream streams.
- Replace tests that encode old `/api/shell/ws?scope=...` assumptions with tests targeting the new game-scoped websocket model.

## Non-Goals
- No GameRoomDO mutation logic.
- No frontend invite or game route runtime rewrite.
- No compatibility shim for the old invalidation websocket or `/presence`-driven flow.

## Deliverables
- Updated `ApiEnv` contract including `GAME_ROOMS`.
- Shared websocket event and client message types with discriminated payloads.
- New D1 migration for `event_seq`, `shell_live_events`, `shell_live_participants`, and `shell_live_join_requests`.
- Shared repository or helper layer for projection and replay persistence.
- Fake D1 and fake Durable Object harness support for downstream tests.

## Required Tests (Spec/Matrix Mapped)
- Spec references: `docs/RIGHELT_WEB_APP_SPEC.md` Sections 4, 5, 6, 8, 11, 12.1.
- Existing references:
  - `packages/api-handler/test/live-transport.test.mjs`
  - `apps/web/test/routing.test.mjs`
  - `apps/web/test/live-sync.test.mjs`
- Additions required:
  - typed websocket event contract tests
  - env and route wiring tests for `/api/shell/games/:id/ws`
  - migration and repository tests for monotonic `event_seq`
  - read-only GET contract tests proving GET game fetch does not mutate presence

## Gap Tests to Add
- Gap: event payload discriminants stay stable when game state shape expands.
- Gap: fake DO namespace can replay events or force `state_sync` fallback deterministically.
- Gap: deleted legacy websocket route is no longer routable.

## Regression Focus
- Remove old isolate-local invalidation assumptions from shared tests and types.
- Prevent future reintroduction of GET-side presence mutation.
- Protect monotonic event sequencing and projection persistence from silent contract drift.
