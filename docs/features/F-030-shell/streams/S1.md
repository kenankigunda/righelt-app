# Stream S1 - Shell Foundation + Routing

## Scope
- Create shell module boundaries for routing, identity/session persistence, shell state, and API facades.
- Keep all board integration behind `apps/web/board-adapter-contract.js` and adapter instances.
- Establish first-render bootstrap architecture aligned to fast-start requirements.

## Non-Goals
- No full join/presence/history feature completion.
- No tutorial or offline playground policy completion.
- No final cross-stream integration hardening.

## Deliverables
- Shell routing skeleton for home/game/tutorial entry points.
- Foundational shell state container and event wiring.
- Contract tests preventing shell imports of board internals.
- Initial bootstrap-path tests and docs for extension by downstream streams.
