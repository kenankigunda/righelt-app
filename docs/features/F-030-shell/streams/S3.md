## Section 12.1 Traceability Ledger
- Implemented and behavior-covered:
  - Offline-local games stay out of home listings until explicit `Go online`.
  - Reconnect availability does not auto-publish an offline-local game.
  - Offline-local reload restore persists local game state through transport storage.
  - `Go online` requires confirmation and restores normal online affordances after promotion.
- Implemented but weakly tested:
  - Browser-driven online/offline event timing while a tutorial route is active.
  - Offline-local continuation/control edges after deeper multi-turn local play.
- Contradicted by implementation:
  - None after the offline-mode hardening pass.
- Missing capability:
  - First-visit cold offline boot without any previously cached shell assets remains unsupported by design and is surfaced as an unsupported state rather than implied support.
