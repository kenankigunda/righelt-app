# A3 Split-Stack Delivery And Ops

## Scope

- Update local dev scripts, CI, deploy workflow, and runbooks for the new split-stack deploy order.
- Make direct Worker health and Pages proxy health first-class smoke checks.

## Non-Goals

- No staging/prod environment split in this step
- No auth/session redesign

## Deliverables

- split-stack dev commands
- deploy workflow that migrates and deploys `righelt-api` before Pages
- runbooks describing required manual bindings and recovery flow

## Test Plan

- Spec surface: deploy and recovery instructions must match the implemented runtime ownership
- Regression focus:
  - CI includes dedicated Worker tests
  - deploy workflow validates direct Worker URL and proxied Pages URL
  - D1 helper and migration commands target `apps/api`
- Acceptance:
  - `pnpm typecheck`
  - `pnpm test:engine`
  - `pnpm test:api-handler`
  - `pnpm test:api-worker`
  - `pnpm test:web`
