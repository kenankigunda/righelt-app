# A2 Pages Proxy Conversion

## Scope

- Convert Pages from combined runtime to same-origin `/api/*` proxy.
- Remove Pages-owned DB and Durable Object bindings.
- Preserve request/response and WebSocket behavior through the proxy.

## Non-Goals

- No direct browser use of `workers.dev`
- No CORS-based client migration

## Deliverables

- Pages Function proxy for `/api/*`
- Pages config-file mode Wrangler config
- Proxy-specific regression tests

## Test Plan

- Spec surface: same-origin browser contract remains `https://righelt.pages.dev/api/...`
- Regression focus:
  - `API_SERVICE` forwarding preserves status, headers, and body
  - local dev fallback reaches `http://127.0.0.1:8787`
  - stable 500 on missing service binding
- Acceptance:
  - `pnpm test:web`
  - `pnpm test:api-worker`
