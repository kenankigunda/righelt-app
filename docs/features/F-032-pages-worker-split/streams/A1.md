# A1 API Runtime Extraction

## Scope

- Create `apps/api` as the dedicated Worker runtime.
- Keep `packages/api-handler` as the shared implementation module.
- Move D1 and Durable Object ownership to `apps/api`.

## Non-Goals

- No browser-visible route changes.
- No Pages proxy changes in this step.

## Deliverables

- `apps/api` Worker entrypoint + Wrangler config
- Worker-entry regression tests
- `GameRoomDO` exported from the dedicated Worker runtime

## Test Plan

- Spec surface: same `/api/*` contract as current runtime
- Regression focus:
  - `/api/health` healthy with DB + `GAME_ROOMS`
  - `/api/health` unhealthy when `GAME_ROOMS` is missing
  - `GameRoomDO` remains exported
- Acceptance:
  - `pnpm test:api-handler`
  - `pnpm test:api-worker`
