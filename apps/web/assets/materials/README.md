# Marble material candidates

`marble-white-raster-v1.webp` is a neutral material texture generated with the built-in image tool on 1 November 2026. It follows the white expressive marble direction in approved T118 reference R01. It contains no interface, brand mark or narrative artwork. The fourteen approved opponent delivery assets remain separate and unchanged.

The delivery is an opaque 1024 × 1024 WebP, 30,970 bytes, converted with `cwebp -resize 1024 1024 -q 78 -metadata none`. The prospective limits were fixed before generation: one shared texture, at most 96 KiB transferred and 1024 × 1024 pixels. Four bytes per pixel gives a 4 MiB decoded RGBA upper bound. This is not a measured heap or latency result. The material test checks the delivery format and limits.

The canvas uses the existing texture beneath a static white mineral-field SVG with fine gray branches and selective colored crystalline fragments at exposed margins. The canvas SVG follows the viewport width so both margin families remain visible on narrow and wide pages. Raised faces use the same cached URL with an 88% white wash, deliberately calmer than the canvas underpaint. Opaque white CSS remains the fallback. These layers have no script, animation or layout ownership.

Prompt: “Create a single production material texture tile, square 1024 by 1024. Use case: photorealistic-natural. Asset: subtle WHITE expressive marble for a web application's background and raised panels, intensity 2. Top-down orthographic scan of polished white Carrara marble, no perspective, lighting uniform and diffuse. Irregular natural branching mineral veins in neutral pale gray with occasional fine darker gray fissures, broad quiet WHITE regions for text, tiny organic mineral variations, refined crystalline structure. Natural veins must be uneven, delicate, branching, fragmented and varied in width, not vector zigzags, parallel ribbons, geometric seams or repeating diamonds. Sparse medium-gray accents, mostly white with restrained neutral gray; no beige or cream. Seamless edges for repeating CSS tile. Absolutely no UI, text, letters, logo, icons, borders, cards, objects, shadows, red or blue marks, photographic scenery, watermark. This is ONLY the material surface; brand-colored edge details will be composed separately. Avoid high-contrast black veins, noisy grain, overdramatic heavy veining. Return only the square opaque texture.”

The generated original was 1254 × 1254 and is retained privately. Historical native Home and Account samples had bounded acceptance; the original raster clusters are denser and larger than R01. The current canvas composition attenuates those clusters below a calmer white field and replaces the literal colored zigzags. Its native reference comparison remains pending until the current prototype is inspected. This is not exact reproduction or acceptance of every foundation surface, zoom state or performance budget. Earlier SVG attempts remain in checkpoint history. `marble-face.svg` is retained as an earlier static exploration; the current face token uses the raster.
